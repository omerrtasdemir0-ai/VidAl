# VidAl

YouTube videolarını istediğiniz çözünürlükte bilgisayara indiren Windows uygulaması ve Chrome eklentisi.

## İndir

**[Son sürümü indir (Releases)](../../releases/latest)**

- `VidAl_Kurulum_x.exe`: Windows kurulumu. Python veya başka bir şey gerekmez.
- `VidAl_Chrome_Eklentisi.zip`: Chrome eklentisi (isteğe bağlı).

## Özellikler

- Link kopyalayınca otomatik algılama
- 144p'den 4K'ya kalite seçimi, MP3 / M4A ses
- İndirme kuyruğu, oynatma listesi indirme, altyazı ekleme
- Chrome eklentisi: YouTube'da "İndir" butonu, sağ tık menüsü, `Alt+Shift+D`
- Kendini otomatik günceller (program ve indirme motoru)

## Chrome eklentisini kurma

1. Zip'i bir klasöre çıkarın.
2. Chrome'da `chrome://extensions` sayfasını açın, sağ üstten **Geliştirici modu**'nu açın.
3. Çıkardığınız klasörü sayfaya sürükleyip bırakın.

Yalnızca indirme izniniz olan içerikler için kullanın.
